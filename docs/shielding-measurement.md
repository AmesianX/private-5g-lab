# 차폐함 누설 계측 — 검출 안 됨

2026-10-15. TOJOIN MS3020-A 차폐함이 실제로 전파를 가두는지, 같은 기종 SDR 두 대로
송신과 수신을 나눠 측정했다.

## 장비

두 대 모두 제원이 같다. UHD 프로브로 확인했다.

| | 송신 `5JKRCXX` | 수신 `RF01FPI` |
|---|---|---|
| name | LibreSDR_B220mini | LibreSDR_B220mini |
| product / revision | 2 / 4 | 2 / 4 |
| FW / FPGA | 8.0 / 16.0 | 8.0 / 16.0 |
| 주파수 범위 | 50 ~ 6000 MHz | 50 ~ 6000 MHz |
| RX 게인 | 0 ~ 76 dB | 0 ~ 76 dB |

송신기는 차폐함 안쪽 안테나로만 연결돼 있고, 수신기는 **포트 4개에 모두 안테나**를 달아
실내 공기를 듣는다. `gnb.yml` 의 `serial=` 핀이 송신기를 `5JKRCXX` 로 고정하므로
안테나가 달린 수신기 쪽으로는 절대 송신되지 않는다.

> 송신기가 사용 중일 때는 `uhd_find_devices` 에 수신기만 보인다. 한 대만 보인다고
> 나머지가 빠진 것으로 읽지 말 것.

## 방법

절대 전력(dBm)은 말할 수 없다. 교정된 신호원이 없기 때문이다. 그래서 **송신 켬/끔의
차이**만 본다. 차이가 잡음바닥 흔들림 이내면 누설은 검출 한계 아래라는 뜻이다.
아무것도 송신하지 않는 3300 MHz 를 같은 회차에 함께 재서 흔들림의 크기를 잡았다.

```bash
sudo python3.12 tools/leakscan.py RF01FPI 60 \
  3350010000:"우리셀" 3345600000:"SSB" 3300000000:"기준"
```

게인 60 dB, 대역 2 MHz, 400k 샘플(앞 10%는 정착 구간이라 버림), 포트 4개.

## 결과 (dBFS)

| 주파수 | 송신 켬 | 송신 끔 | 차이 |
|---|---|---|---|
| **3350.01 MHz** 우리 셀 중심 | −55.13 / −54.96 / −54.09 / −53.57 | −55.42 / −55.06 / −54.06 / −53.66 | +0.29 / +0.10 / −0.03 / +0.09 |
| **3345.6 MHz** SSB | −55.41 / −54.96 / −53.92 / −53.44 | −55.43 / −54.92 / −53.91 / −53.50 | +0.02 / −0.04 / −0.01 / +0.06 |
| 3300 MHz 기준(무송신) | −55.28 / −54.98 / −52.53 / −53.12 | −55.28 / −54.75 / −52.50 / −53.14 | 0.00 / −0.23 / −0.03 / +0.02 |

순서는 ch0 TX/RX · ch0 RX2 · ch1 TX/RX · ch1 RX2.

**우리 셀 주파수의 켬/끔 차이가 무송신 기준 주파수의 흔들림과 같다.** 누설 신호가 없다.

## 이 음성 결과가 진짜라는 증거

"안 보인다"는 결과는 수신기가 고장났을 때도 똑같이 나온다. 그래서 같은 설정으로
상용 5G 하향을 재서 계통이 살아 있음을 확인했다.

| 주파수 | 최고 포트 | 잡음바닥 대비 |
|---|---|---|
| 3450 MHz | −32.67 dBFS | **+21 dB** |
| 3550 MHz | −42.22 dBFS | +12 dB |
| 3650 MHz | −17.86 dBFS | **+37 dB** |

수신기와 안테나는 멀쩡하다. 우리 주파수에서 안 보이는 것은 장비가 못 본 게 아니라
**없는 것**이다. 덤으로, 우리 셀 바로 옆에 상용 5G 가 이만큼 강하게 떠 있다는 사실도
숫자로 남았다 — 공중 방사 실험이 왜 금지인지에 대한 근거다(부록 D).

## 한계

- **절대값은 모른다.** 교정 신호원이 없어 dBm 으로 환산할 수 없다. 차이만 유효하다.
- 재현 흔들림이 약 0.3 dB 이므로 검출 한계는 2 MHz 대역에서 **잡음바닥보다 약 11 dB 아래**다.
  그보다 작은 누설은 이 방법으로 못 잡는다.
- **수신 안테나와 차폐함 사이 거리를 기록하지 않았다** [검증 필요]. 가까울수록 민감하므로
  이 결과를 인용할 때는 거리를 재서 함께 적어야 한다.
- 측정 대역이 2 MHz 라 20 MHz 반송파의 일부만 본다. 다만 SSB 와 중심 주파수를 모두
  재서 주요 성분은 덮었다.
- 상자 전체가 아니라 **지금 이 배선 상태**를 잰 것이다. 관통 단자나 뚜껑 체결을 바꾸면
  다시 재야 한다.

## 다음

- 뚜껑 연 상태와 닫은 상태를 같은 회차에 비교하면 상자의 감쇠량 자체를 얻을 수 있다.
  다만 **연 상태는 공중 방사**이므로 송신 게인을 최소로 내린 뒤에만 할 것.
