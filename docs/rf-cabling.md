# RF 배선 — B210 ↔ 모뎀 전도시험

작성 2026-10-05. 모뎀 입고 시점.

## 결론 먼저

```
B210                                                    모뎀 (RM520N-GL)
┌──────────┐                                        ┌──────────┐
│  단자 A  ├──SMA──[감쇠기 40dB]──SMA──[MHF4]──────┤ ANT1     │  ← PRX  실측 RSRP -112
│  단자 B  ├──SMA──[감쇠기 40dB]──SMA──[MHF4]──────┤ ANT2     │  ← DRX  실측 RSRP -103
│  나머지  ├──[50Ω 종단]                            │ ANT3     ├──[50Ω 종단]  RX2 (SINR -20)
└──────────┘                                        │ ANT4     ├──[50Ω 종단]  RX3 (SINR -20)
                                                     └──────────┘
```

**케이블 두 가닥, 각각 40 dB 감쇠기.** 모뎀 ANT3·ANT4 는 종단기.
n78은 TDD라 송수신이 시간으로 갈린다.

## 경로별 수신 세기 (2026-10-14 실측)

```
AT+QRSRP  ->  +QRSRP: -112,-103,-102,-71,NR5G     # <PRX>,<DRX>,<RX2>,<RX3>
AT+QSINR  ->  +QSINR: 11,19,-20,-20,NR5G
```

- 케이블 경로(PRX/DRX)만 유효. SINR -20 은 "측정 없음"이고 종단 포트의 정상 결과.
- **종단 포트 RX3 의 RSRP 칸에 -71 찌꺼기가 남아 있고, `AT+QENG` 가 그 값을 보여 준다.**
  게인 판단에 `AT+QENG` 의 RSRP 한 칸을 쓰지 말 것. 반드시 `AT+QRSRP` 네 칸을 본다.
- 링크 예산(게인 80, 감쇠 40 dB → RSRP -71 예상) 대비 실측 -103/-112 로 30~40 dB 낮음. 원인 미규명.
- 같은 규격으로 물린 두 경로가 9 dB 차이(-112 vs -103). 커넥터 체결 상태 의심.

## B210 단자

| 단자 | 용도 |
|---|---|
| TX/RX | 송신 + TDD 수신 겸용 ← **이것만 쓴다** |
| RX2 | 수신 전용 (FDD용). TDD 단일포트 구성에선 미사용 |

- 정품 B210은 **SMA 암(female)**. 우리 건 LibreSDR 클론이라 **육안 확인 필요**.
  가운데 핀이 튀어나왔으면 수, 구멍이면 암. RP-SMA면 암수가 뒤바뀐 규격이라 어댑터 필요.
- UHD 안테나 이름이 `"TX/RX"` 와 `"RX2"` 다. TDD 단일포트면 **rx 안테나도 `"TX/RX"` 로** 지정해야 한다.

## 모뎀 단자 — 형태별로 다름

| 형태 | 커넥터 | 필요한 것 |
|---|---|---|
| M.2 모듈 (RM520N-GL 등) | **MHF4** (1.5mm) | MHF4-to-SMA 피그테일 **필수** |
| 구형 M.2 / mPCIe | U.FL | U.FL-to-SMA 피그테일 (MHF4와 비호환) |
| USB 동글 / 산업용 | SMA 암 또는 TS-9 | TS-9면 TS-9-to-SMA |
| 개발보드 | 보통 SMA 암 | SMA 수-수 케이블 |

모뎀 안테나 단자는 보통 여러 개(`ANT0/MAIN`, `ANT1/DIV`, MIMO, GNSS).
**1T1R 이므로 MAIN 만 연결**하고 나머지는 종단하거나 비운다.

## 감쇠 — 양방향 모두 보호

### 상향이 더 위험하다

| 항목 | 값 |
|---|---|
| 모뎀 최대 송신 | **+23 dBm** (200 mW, power class 3) |
| B210 수신 정상 범위 | -15 dBm 이하 |
| B210 수신 손상 임계 | **0 dBm 부근** |

감쇠 없이 직결하면 **B210 수신단이 즉사한다.**

```
+23 dBm - 40 dB = -17 dBm   → 안전 범위 안
```

### 하향은 여유가 크다

```
B210 송신 -10 dBm - 40 dB = -50 dBm   → 모뎀엔 아주 강한 셀
```

UE 개방루프 전력제어가 경로손실 40dB를 보고 PRACH 를 알아서 약하게 쏜다.
그래도 설정 오류 대비해 **최악(+23dBm) 기준으로** 감쇠를 잡는다.

### 권장값

- **총 40 dB.** 30+10 또는 20+20 직렬도 가능. 50dB 면 더 안전하고 하향도 충분.
- **정격 1W 이상** (모뎀 +23dBm 수용). 흔한 2W SMA 감쇠기면 충분.

## 작업 순서

1. **송신 끈 상태에서** 케이블 전부 조립
2. 감쇠기 체결 확인 ← 여기 빠지면 B210 사망
3. gNB 기동, **tx_gain 최소부터**
4. UE 가 셀을 보는지 확인. 안 보이면 5 dB 씩 올림

**금지: 송신 중 커넥터 체결/해제.** PA 가 열린 부하를 보면 손상되고 스파이크가 뜬다.

## 차폐함 없이 해도 되나

동축 직결 + 감쇠기로 닫힌 경로면 공중 방사는 거의 없다. 단:

- 커넥터가 느슨하면 거기서 샌다. 손으로 확실히 조일 것
- 종단 안 한 단자가 안테나 역할을 한다 → 50Ω 종단 권장
- 3349.92 MHz 는 SKT 하단(3600)과 **31 MHz 이격**. 여유가 크지 않다

**차폐함(TOJOIN MS3020-A) 오면 그 안에 모뎀을 넣는 것이 정석.**
그 전까지는 tx_gain 최소 + 짧은 확인만. 본격 시험은 차폐함 이후로.

## 이 머신의 모뎀 도구 현황 (2026-10-05 확인)

| 도구 | 상태 |
|---|---|
| `mmcli` / ModemManager | 있음, 서비스 enabled+active |
| `qmicli` / `mbimcli` | 있음 |
| `pcscd` | 있음 (SIM 리더는 미검출) |
| `minicom` `picocom` `socat` `screen` | **없음** — AT 커맨드 직접 쓰려면 설치 필요 |

주의: ModemManager 가 active 라 모뎀을 꽂으면 자동으로 붙잡는다.
AT 포트를 직접 쓰려면 해당 포트를 ModemManager 관리에서 빼거나 서비스를 잠시 멈춰야 한다.
